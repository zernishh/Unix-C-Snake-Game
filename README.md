## Overview  
A terminal-based snake game implementing:  
- Wrap-around map movement  
- Generic linked list for UNDO functionality  
- Dynamic map loading from text files  

This showcase highlights my ability to develop C89-compliant systems with memory safety and modular architecture while adhering to strict academic guidelines.  

## Key Features  
**Core Systems**  
- POSIX terminal control (raw input/output)  
- Valgrind-verified memory management  
- Makefile with conditional compilation  

**Game Mechanics**  
- Wrap-around movement logic  
- Randomized snake behavior  
- Collision detection system  

**Advanced Features**
